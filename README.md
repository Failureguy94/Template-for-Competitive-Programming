# Competitive Programming snippets in CPP
This is the repo purely made to maintain the template for competitive programming in CPP making the code faster and easier to read 

## Current Contents
The snippet contains the following things in cpp:
1.**CP**: FastIO, with solve function for multiple test cases with redefined macros.
2.**Binary Exponentiation**: To Find the powers of numbers using BIT Manipulation in an efficient way to handle large test cases.
3.**Precomputing**: To precompute maximum and sum of all elements from i=0 to i=j ,0<=j<=n-1.
